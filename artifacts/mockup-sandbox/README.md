# Mockup sandbox

This is a separate Vite/React visual sandbox containing a copied UI component set. It is useful for interface exploration but is not the API-connected Trinity product and should not be used as evidence that a backend feature works.

```bash
pnpm --filter @workspace/mockup-sandbox run dev
pnpm --filter @workspace/mockup-sandbox run typecheck
pnpm --filter @workspace/mockup-sandbox run build
```

The production application is [`../trinity/`](../trinity/).
